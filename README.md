# Telegram-статьи

Плагин для Obsidian. Отправляет заметку или её часть в Telegram как **Rich Message**: в сообщении сохраняются заголовки, таблицы, цитаты, сворачиваемые блоки, формулы, чеклисты и картинки. Плагин использует метод `sendRichMessage` из Bot API 10.1+. Отдельный сервер не нужен, запросы идут прямо из Obsidian.

## Возможности

- **Отправить заметку в Telegram**: команда в палитре и пункт в контекстном меню файла. После первой отправки во frontmatter записываются `tg_chat_id` и `tg_message_id`. При повторной отправке плагин **редактирует** уже опубликованное сообщение, а не присылает новое.
- **Отправить как новое сообщение**: сохранённые id игнорируются, отправляется новое сообщение, и его id записываются во frontmatter.
- **Отправить выделенное**: команда и пункт в контекстном меню редактора. Выделенный фрагмент всегда уходит новым сообщением, frontmatter не меняется.
- **Предпросмотр и выбор разделов**: в окне слева дерево заголовков с галочками, справа итоговый Rich Markdown в том виде, в каком он уйдёт в API. Там же счётчик символов и замечания конвертера. Если выбрана вся заметка, сообщение обновляется по сохранённым id. Если выбрана часть, она уходит новым сообщением.

## Как заметка превращается в сообщение

| В Obsidian | В Telegram |
|---|---|
| frontmatter, `%%комментарии%%`, `<!-- -->` | вырезаются |
| блоки `dataview` / `dataviewjs` | вырезаются |
| строки с `#тегами` в конце заметки | вырезаются |
| `[[Заметка]]`, `[[Заметка\|алиас]]`, `[[Заметка#Раздел]]` | текст: «Заметка», «алиас», «Заметка › Раздел» |
| `[текст](url)` | без изменений |
| `> [!note] Заголовок` | цитата с жирным заголовком и иконкой |
| `> [!tip]- …` / `> [!tip]+ …` | сворачиваемый блок `<details>` (`+` — раскрытый) |
| `![[кот.png]]`, `![](папка/кот.png)` | файл загружается вместе с сообщением и встраивается |
| `![](https://…/a.png)` | встраивается по URL; в настройках можно оставить ссылкой |
| `![[Другая заметка]]` | название заметки (встраивание заметок не поддерживается) |
| `==выделение==` | маркер, как в Telegram; в настройках можно выбрать жирный |
| `$x^2$`, `$$…$$` | формулы; многострочные превращаются в блок ```` ```math ```` |
| `$` в ценах («100$», «$5») | экранируется и не становится формулой |
| код (блоки и `` `inline` ``) | не меняется вообще |
| таблицы, списки, чеклисты, сноски `[^1]` | без изменений: Telegram понимает их сам |

Лимиты Telegram: до 32 768 символов, 500 блоков, 50 вложений и 20 колонок в таблице. Фото до 10 МБ, остальные файлы до 50 МБ. Если заметка длиннее лимита, плагин её **не обрезает**: он показывает текущую длину и не отправляет. В таком случае отправьте заметку по частям через «Предпросмотр и выбор разделов».

## Настройка

### 1. Создать бота

1. Откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте имя и username: он должен заканчиваться на `bot`.
3. BotFather пришлёт токен вида `123456789:AA…`. Это пароль от бота, никому его не показывайте.

### 2. Вставить токен

Откройте настройки Obsidian → «Telegram-статьи» → «Токен бота» и создайте новый секрет с токеном. Токен хранится в хранилище секретов Obsidian на этом устройстве (нужен Obsidian 1.11.4+). В файлы хранилища и в синхронизацию он не попадает, поэтому на каждом устройстве его нужно ввести отдельно. Кнопка «Проверить» покажет username бота.

### 3. Узнать chat_id

Бот не может написать первым, поэтому:

1. Найдите своего бота в Telegram и отправьте ему `/start`.
2. В настройках плагина нажмите **«Определить»**. Плагин спросит у Telegram, кто последний писал боту, и подставит ваш числовой id.

Другой способ: узнать id у [@userinfobot](https://t.me/userinfobot) и вписать его вручную.

> Если у бота настроен webhook, «Определить» не сработает: Telegram не отдаёт `getUpdates`, пока webhook включён. Тогда впишите id вручную.

### Отправка в канал или группу

Плагин рассчитан на личку, но в поле chat_id можно указать и канал: `@имя_канала` или числовой `-100…`. Для этого:

1. Откройте канал → «Управление каналом» → «Администраторы» → «Добавить администратора».
2. Найдите бота по username и включите право **«Публикация сообщений»**. Чтобы повторная отправка обновляла пост, включите ещё **«Редактирование сообщений»**.
3. Сохраните изменения.

Поле «Тема (message_thread_id)» нужно только для форумов и для лички, в которой у бота включён режим тем.

## Установка вручную

1. Соберите плагин (`npm install && npm run build`) или скачайте `main.js`, `manifest.json` и `styles.css` из релиза.
2. Создайте папку `<хранилище>/.obsidian/plugins/telegram-rich/`.
3. Скопируйте в неё `main.js`, `manifest.json` и `styles.css`.
4. Перезапустите Obsidian или обновите список плагинов. Затем включите «Telegram-статьи» в разделе «Сторонние плагины».

Через BRAT: добавьте адрес репозитория в «BRAT → Add beta plugin».

## Разработка

```bash
npm install
npm test          # юнит-тесты конвертера, разделов и клиента (vitest)
npm run check     # проверка типов
npm run build     # main.js
```

Устройство кода:

- `src/convert.ts`: чистая конвертация Obsidian → Rich Markdown, без Obsidian API;
- `src/sections.ts`: разбивка заметки по заголовкам;
- `src/telegram.ts`: клиент Bot API, multipart собирается вручную; HTTP передаётся снаружи (`requestUrl`);
- `src/main.ts`, `src/settings.ts`, `src/modal.ts`: сам плагин.

Живая проверка без Obsidian: `TG_TOKEN=… TG_CHAT=… npx tsx scripts/live-test.ts`. Скрипт отправит тестовую заметку с картинкой, а потом отредактирует её.
